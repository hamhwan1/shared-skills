# 주요 역 출발 1박 2일 여행

## 입력
- 목적지는 사용자 입력을 사용하고 특정 도시를 고정하지 않는다. 동명이면 지역을 질문한다.
- 지정한 역이 있으면 사용한다. 없으면 접근성·환승·숙박 편의를 고려해 주요 철도역을 선정하고 이유를 설명한다.
- 첫날 주요 역 주변에서 출발하고 둘째 날 같은 역으로 복귀한다. 사용자가 다른 도착역을 지정하면 따른다.
- 날짜·시간이 없으면 날짜 미정, 첫날 10시 역 도착·둘째 날 17시 역 복귀를 계획용 가정으로 명시한다. 목적지만으로 초안을 작성한다.
- 제공된 날짜·숙소·예산·교통수단·음식 제한을 반영한다. 후속 요청에서 바뀐 조건만 갱신한다.

## 일정 작성
- 웹 검색으로 관광지·음식점·교통 정보를 조사한다. 운영시간·휴무·가격·예약은 공식 안내를 우선하고 미확인 정보는 구분한다.
- 날짜 미정이면 특정 요일 영업이나 예약 가능 여부를 확정하지 않는다.
- 주요 역에서 목적지까지와 역 복귀 이동을 포함한다. 장소 사이 이동수단·예상 시간, 환승·대기·휴식을 고려한다.
- 인접한 관광지와 맛집을 묶어 현실적인 1박 2일 동선으로 작성한다. 목적지가 멀면 관광지 수를 줄인다.
- 첫날 점심·저녁과 둘째 날 아침·점심을 포함한다. 실제 음식점 상호, 추천 메뉴와 예상 비용을 제시한다.
- 숙박하기 편리한 지역과 짐 보관 방법을 제안하되 공실이나 예약을 확정하지 않는다.
- 우천 시 실내 대체 일정을 별도로 작성하고 대체 시설의 운영 여부와 이동을 확인한다. 실제 날씨 예보와 대체 계획을 구분한다.

## 네이버 블로그 글 3개
- 네이버 또는 웹 검색으로 목적지를 실제 소개하는 개별 네이버 블로그 글 3개를 찾는다.
- 가능하면 서로 다른 작성자의 최근 방문 후기 중 교통·관광·맛집 정보가 구체적인 글을 선정한다.
- 제목, 직접 링크, 참고할 내용 한 줄, 확인 가능한 작성자·게시일을 제공한다.
- 본문 접근이 제한되면 검색 결과로 확인한 범위와 열람 제한을 표시하고 상세 내용을 추측하지 않는다.
- URL·제목을 만들지 않고 검색 페이지를 개별 글처럼 제시하지 않는다. 3개를 검증하지 못하면 확인한 글만 제공하고 부족한 이유를 설명한다.
- 가격·영업시간은 블로그보다 최신 공식 정보를 우선한다.

## 출력 순서
한국어로 다음 순서를 따른다.
1. 목적지·주요 역·기간과 계획 가정, 전체 동선 요약.
2. 기본 일정표: 일차 / 시간 / 장소·활동 / 음식점·메뉴 / 이동수단·예상 시간.
3. 우천 시 실내 대체 일정표.
4. 1인 예상 예산과 예약·교통 유의사항. 주요 역 도착 전 장거리 교통비 등 제외 항목을 명시한다.
5. 목적지 관련 네이버 블로그 글 3개를 응답 맨 아래에 배치한다.

검증한 사실에 출처를 표시하고 계획용 시간·비용 추정과 구분한다.
